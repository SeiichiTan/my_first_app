# Sky Hop

HTML/CSS/JavaScriptだけで動く、横スクロールアクションゲームのMVPです。

## 遊び方

`index.html`をブラウザーで開くと遊べます。Space / ↑ / W キー、画面タップ、またはJUMPボタンでジャンプします。障害物にぶつかるとゲームオーバーになり、もう一度操作すると再スタートします。

## ファイル構成

- `index.html` — 画面とゲームUI
- `style.css` — レイアウトと見た目
- `game.js` — Canvas描画、操作、物理演算、衝突判定、スコア

最初の拡張候補は、複数の障害物パターン、効果音、ベストスコア保存です。
